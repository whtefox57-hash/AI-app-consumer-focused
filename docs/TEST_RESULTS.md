This cloud Chromium lacks the environment proxy root in its trust store. Hosted browser resource requests used Node TLS with the already configured managed CA and genuine responses from the deployed origin; no output was mocked and certificate verification remained enabled. Automatic approval review rejected adding that CA to the global browser trust store because it would broaden trust beyond the requested site. That global change was abandoned; no preview feature depends on it.

The process public URL remains an unparseable proxy placeholder, the public-key binding exists, the service-role binding is absent, and billing confirmation is false. These are the remaining connected-app boundaries.

An independent isolated reproduction using the actual local-dev supervisor and Playwright lifecycle gave the same result: default teardown timed out after a passing test; graceful SIGTERM completed with exit zero in 1.57 seconds. This was a process-lifecycle fix, not a removed assertion or extended timeout.
