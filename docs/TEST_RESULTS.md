These probes did not send personal data or attest billing. Personal app calls remain disabled until project billing is confirmed.

Apple search returned two real catalog tracks and HTTPS links; authenticated application acceptance remains pending. A bounded synthetic current-model speech diagnostic did not return supported audio, so speech remains disabled. Grounded research remains disabled pending compliance with current Search Suggestions and retention requirements.

The Gemini key is already bound and never printed. The managed Supabase URL is known; browser public bindings were mistakenly delivered as opaque proxy secrets, and the backend service-role binding is absent. Automatic configuration review rejected changing those existing direct-variable entries; owner editing is required. Saved setup is separate from deployed host settings.

GitHub initially denied Pages creation with `403 Resource not accessible by integration`. The owner then selected GitHub Actions in Pages settings; the official API verified workflow publication with HTTPS enforced. Earlier remote CI runs timed out. New workflows bound readiness/test duration and preserve diagnostics; remote success must be read from the current run, never inferred from local checks.
