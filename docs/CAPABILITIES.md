## Provider configuration

`src/lib/ai.ts` implements a `Provider` interface so the UI and persistence do not depend on the Gemini SDK. Defaults are concrete: `gemini-flash-latest` for text, optional `gemini-pro-latest` for difficult work, configurable transcription and TTS models. `gemini-flash-latest` is shown in the official installed Google SDK README. On 2026-10-02 the text alias returned `gemini-3.8-flash` in a real synthetic generation. A separate synthetic generation verified stable `gemini-3.5-flash-lite`; pin this lower-cost ID for the recommended production cost plan. Current official model, price and paid-data documentation was verified. Alias targets may change. Strong-model metadata is readable, but strong generation is untested. A synthetic current-model TTS diagnostic failed to return supported audio; speech remains disabled.

Text and streaming paths are implemented. Structured output is an explicit SDK capability but no user workflow currently invokes it. External action tools and image input are disabled. Grounded search and speech are opt-in flags, not proof of live connectivity. A configured key is labeled “live validation pending” in the app. A successful deployed request is still required.
